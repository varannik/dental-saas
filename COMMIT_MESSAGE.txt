fix(local-dev,auth,web): Docker DB URL hygiene, auth 4xx payloads, register errors, smoke + docs

Align host-run services and smoke checks with Docker Postgres on **host :5433**, fix misleading
auth JSON for client errors (e.g. duplicate email), improve register UI messaging, and add
operator helpers (smoke preflight, DB list script, tenant-management plan).

Auth service

- **`error-response.ts`** For **4xx**, `error` and `message` now echo the real client-safe detail
  (e.g. *User with this email already exists.*); **5xx** keep generic `Internal Server Error` in
  production with detail only in dev. Fixes browsers showing **Internal Server Error** on **409**.

Web app

- **`register/page.tsx`** Prefer `message` then `error` from API JSON; explicit fallback for **409**
  when the body is still generic.

Local dev scripts

- **`scripts/dev/start-services.sh`** If `DATABASE_URL` targets `@localhost:5432` or
  `@127.0.0.1:5432`, rewrite to the Docker host URL on **:5433** (with warning). Opt out with
  `SKIP_DOCKER_DATABASE_URL_NORMALIZE=1`. Explains conflict with dotenv **override: false** when the
  shell exports legacy native Postgres.

Gateway smoke checks

- **`gateway-smoke-checks.sh`** Header note on :5433 vs :5432; preflight: reject first `DATABASE_URL`
  in `.env*` using :5432; reject shell `DATABASE_URL` using :5432; verify **`public.users`** exists
  in `dental-saas-postgres` before HTTP steps (prompts `make db-migrate`).

Environment template

- **`.env.example`** Note that a shell-set `DATABASE_URL` overrides repo `.env*` (dotenv does not
  override existing env).

Docs & tooling

- **`docs/ux/web-tenant-management.md`** Phased best-practice plan for tenant/session UI + backend
  gaps (create-tenant membership, `/me`, switch-tenant).
- **`scripts/database/tests/list-users-tenants.sh`** Read-only listing of `tenants`, `users`, and
  `user_tenants` via Docker `psql` (sources `../../lib/{common,docker}.sh`).

Validation

- `bash -n scripts/dev/start-services.sh scripts/test/gateway-smoke-checks.sh scripts/database/tests/list-users-tenants.sh`
- Local: `unset DATABASE_URL` or `:5433`, `make docker-up`, `make db-migrate`, `make start-services`,
  `make gateway-smoke-checks`
- Register duplicate email: expect **409** with clear API `error` / UI copy
