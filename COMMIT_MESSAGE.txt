feat(gateway,infra,env): harden auth proxy headers, fix compose DB URL, document local env

Improve API-gateway behavior for browser-backed requests (where duplicate headers appear as
arrays), align Docker Postgres wiring for auth, and tighten root `.env` / `.env.example` guidance
for host-vs-container databases and gateway discovery.

API gateway

- **`http-header:firstHeader()`** Normalizes duplicate incoming headers (`content-type`,
  `authorization`, `x-request-id`) to plain strings before `fetch()`. Duplicate header values expose
  as `string[]` in Fastify; passing them straight into Undici rejects and surfaced as opaque **500s**
  while `curl` (single-valued headers) still worked.
- **Auth proxy (`auth.proxy.ts`)** Uses `firstHeader`, derives upstream path via `upstreamAuthPath`
  (pathname only, tolerant of uncommon full-URL shapes), and serializes outbound bodies via
  `serializeProxyBody` (`string` bodies forwarded as-is instead of double-`JSON.stringify`).
- **`src/lib/__tests__/http-header.test.ts`** Covers `firstHeader` array/single/unset inputs.

Infrastructure

- **`docker-compose.yml` (`auth` service)** Set `DATABASE_URL` to `@postgres:5432` inside the Compose
  network (`5433` is only the host port mapping; inter-container Postgres is **5432**). Matches
  `users` and `clinical` services.

Environment templates (repo root)

- **`.env` / `.env.example`** Document dotenv load order (`*.local` overrides), host
  **`localhost:5433`** targeting Docker-published Postgres versus compose-time `postgres:5432`, and
  add **`DB_*`** helpers for scripts.
- Declare **`GATEWAY_HOST` / `GATEWAY_PORT`**, **`AUTH_SERVICE_URL`**, optional **`CORS_ORIGINS`**
  comment block, **`AUTH_HOST` / `AUTH_PORT`** for host-run auth, and **`NEXT_PUBLIC_API_GATEWAY_URL`**
  as a documented default with a reminder that Next.js reads **`apps/web/.env*`** (copy line there
  when needed).

Validation

- `pnpm --filter @saas/api-gateway test`
- Compose: `docker compose -f infrastructure/docker/docker-compose.yml up -d postgres` (and stack),
  recreate **`auth`** if it cached the old **`DATABASE_URL`**.
- Restart host-run **gateway** / **auth** after `.env` edits; confirm **`DATABASE_URL`** and
  **`.env.local`** are not pinning native Postgres (**`:5432`**) unintentionally.
